# Simple Friends bets and fresh balances

The user explicitly requests a casual private-group workflow without approval, independent resolvers, official sources, evidence or written reasons. Implement inline on the existing stack. This supersedes the earlier Friends governance requirement for the simple workflow; provider-final Live settlement stays separate.

- New default creation requires a question and closing time. Optional description only. Open immediately with fixed 50/50 starting odds and a funded b=100 maker; reject insufficient group subsidy atomically. Existing detailed API payloads remain compatible.
- Creator and active group owner/moderator may settle existing or new Friends bets as YES, NO or neutral cancel, even before the deadline. Close trading, unlock orders, settle exact shares, return residual reserve, save actor/result automatically and notify the group in one transaction. Same-result retries must not pay twice; reject a different finalized result. Never let an ordinary member or another group resolve a bet. No user-written source or reason.
- Compact Friends detail controls explain the decider and payouts. Remove approval and resolution paperwork from normal creation/detail flows. Neutral cancellation pays 0.50 CR per contract; do not promise cost refunds that cannot be backed after peer sales.
- Reproduce balance freshness failures. Pending background fetches must not swallow mutation invalidations. Coalesce one follow-up fetch; ordinary realtime/poll refreshes must still publish slow responses. Reads must release already-expired locks without waiting for a timer. Verify admin adjustments affect only their chosen wallet and persist across API views and restarts.
- Credit-transfer intent is being clarified asynchronously; independently complete the above. Unless explicitly requested, do not add cross-economy transfers or user gifts.
- Test regressions first, then run relevant/full suites, build, production smoke, one fresh review, back up/restart the local app, and push changed/new files as individual commits.
